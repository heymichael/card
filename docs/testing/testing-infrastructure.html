Testing Infrastructure

This page documents the test model for an app repository created from this template.

Current Test Model

App testing should cover three complementary layers:

  • Pull request checks: blocking lint, test, and build validation.
  • Main publish checks: blocking artifact package and metadata validation.
  • Scheduled checks: optional non-blocking regression and docs deep-link checks.

Workflows and Triggers

Workflow wiring is intentionally placeholder in this template and must be finalized per app.

When added, latest report snapshots should be published under /docs/test-status/.
