Callbacks

updateBlock(id: ActiveBlock, updates: Partial<TextBlock>): void

Merges partial updates into the specified text block's state. Used by every control (text, font size, font family, color, alignment).

moveBlock(id: ActiveBlock, x: number, y: number): void

Sets the x/y position of a text block. Called after drag-end on the canvas.

movePhoto(x: number, y: number): void

Updates the photo's x/y position after a drag.

resetPositions(): void

Resets both text blocks to their DEFAULT_BLOCKS positions. If a photo exists, re-centers it scaled to card width.

handleSetActiveElement(id: ActiveElement): void

Sets the active canvas element. If the new element is a text block, also syncs activeBlock so the controls panel updates.

handleSetActiveBlock(id: ActiveBlock): void

Sets the active text block and syncs activeElement to match.

handleAddPhoto(file: File): void

Creates an object URL from a File, loads it as an HTMLImageElement, computes initial scale/position to fit card width, and sets both photo and photoImage state. Revokes any previous object URL. Sets active element to 'photo'.

handleRemovePhoto(): void

Revokes the object URL, clears photo and photoImage, and resets active element to 'blockA' if the photo was selected.

resizePhoto(x: number, y: number, scaleX: number, scaleY: number): void

Updates photo position and scale after a Konva Transformer interaction.

handleExport(): void

Calls canvasRef.current.exportJPEG(), generates a timestamped filename (greeting-card-YYYYMMDD-HHmmss.jpg), creates a temporary <a> element, and triggers a download.

Effects

Keyboard nudge effect (lines 190–251)
Listens for keydown on window. Ignores events when focused on form inputs. Handles:

  • Delete/Backspace on photo: calls handleRemovePhoto()
  • Arrow keys: nudges the active element by 1px (or 10px with Shift)
  • Text blocks are clamped within card bounds; photos are not

Object URL cleanup effect (lines 160–167)
On unmount, revokes any lingering object URL to prevent memory leaks.

Module-level Functions

generateArcPath(x: number, y: number, width: number, arcRadius: number): string

Generates an SVG M ... A ... path for a circular arc. The text block's width becomes the chord length. The arc sweeps clockwise (upward bow). Used when curveType === 'arc'.

ParamDescription
xBlock's x position (arc starts here)
yBlock's y position (vertical baseline)
widthChord length (block width)
arcRadiusCircle radius; smaller = tighter curve
generateWavyBezierPath(x: number, y: number, width: number, amplitude: number): string

Generates an SVG path with 4 chained cubic bezier segments (C commands) that alternate direction, producing a sine-wave-like path with 3 direction changes. Used when curveType === 'wavy-bezier'.

ParamDescription
xStart x
yBaseline y
widthTotal path width, divided into 4 equal segments
amplitudeVertical displacement of control points (wave height)

Imperative Handle

exportJPEG(): string | null

Hides the overlay group, calls stage.toDataURL() at JPEG quality 0.95 with a pixel ratio that compensates for the responsive scale (so output is always full 1500×2100), restores the overlay, and returns the data URL.

Internal Callbacks

updateScale(): void

Measures the container element, computes the scale factor that fits CARD_WIDTH × CARD_HEIGHT within available space (minus 40px padding), capped at 1.0.

clampTextPosition(node: Konva.Text, block: TextBlock): { x, y }

Constrains a text node's position so it stays within the card bounds (0 to CARD_WIDTH - block.width horizontally, 0 to CARD_HEIGHT - textHeight vertically).

handleTextDragEnd(id: ActiveBlock, e: KonvaEventObject<DragEvent>): void

Called on text block drag-end. Clamps the position and commits it to state via onMoveBlock.

handleTextDragMove(id: ActiveBlock, e: KonvaEventObject<DragEvent>): void

Called on every drag-move frame. Clamps position in real-time so the block can't be dragged out of bounds.

handlePhotoDragEnd(e: KonvaEventObject<DragEvent>): void

Called on photo drag-end. No clamping — the photo is allowed to extend beyond card bounds (clipped by the parent Group). Commits position via onMovePhoto.

handlePhotoTransformEnd(): void

Called after the Konva Transformer finishes a resize. Reads the node's new position and scale, commits via onResizePhoto.

Render Helpers

renderSelectionBox(x: number, y: number, w: number, h: number): JSX.Element

Returns a dashed blue <Rect> with 8px padding around the given bounding box. Used for the active text block's selection indicator. listening={false} so it doesn't intercept clicks.

renderTextBlock(block: TextBlock, nodeRef: React.RefObject): JSX.Element

Renders either a Konva <TextPath> (if block.curved is true) or a standard <Text>. Wires up onClick, onTap, onDragStart, onDragEnd, and onDragMove handlers. For curved text, generates the appropriate SVG path via generateArcPath or generateWavyBezierPath based on curveType.

renderPhoto(): JSX.Element | null

Returns a Konva <KonvaImage> if photo and photoImage exist, otherwise null. The image is draggable and wired to selection/drag/transform handlers.

renderTextSelectionBox(): JSX.Element | null

Checks which text block is active, gets its bounding box via getClientRect({ skipTransform: false }), and calls renderSelectionBox. Returns null if a photo is selected.

Effects

ResizeObserver effect (lines 147–152)
Calls updateScale() on mount and whenever the container resizes. Disconnects on cleanup.

Tick effect (lines 201–204)
Increments a counter whenever blocks or photo change, forcing the selection box to recalculate.

Transformer attachment effect (lines 206–216)
Attaches the Konva Transformer to the photo node when activeElement === 'photo', or detaches it otherwise. Triggers a layer redraw.
