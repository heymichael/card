Testing Infrastructure

This page documents the test model for an app repository created from this template.

Current Test Model

App testing should cover three complementary layers:

  • Pull request checks: blocking, impact-routed smoke and validation checks.
  • Main publish checks: blocking regression and artifact/contract validation before publish.
  • Nightly checks: non-blocking full regression in test plus minimal production monitor checks.

Workflows and Triggers

  • .github/workflows/ci.yml - pull request checks (suite: pr-checks).
  • .github/workflows/publish-artifact.yml - main publish checks (suite: main-publish-checks).
  • .github/workflows/nightly-checks.yml - nightly suites (scheduled-regression, prod-monitor).

Each workflow generates report artifacts plus docs snapshots under docs/test-status/.

Source of Truth

  • Test status catalog: docs/test-status/catalog.json
  • Testing catalog: docs/testing/catalog.json
  • Check scripts: scripts/checks/
  • Snapshot/report generation: scripts/test-status/
  • Playwright tests: tests/e2e/
