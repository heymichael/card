Test Lineup

Selection: card baseline

Trigger: pull request, main publish, and optional schedule

Environment: repository CI environment

Platforms: app runtime and docs shell routes

PR Checks (Blocking)

  • Lint, unit tests, and build checks pass.
  • Docs generation and sync scripts run cleanly.
  • Requirements/testing catalogs parse and link targets exist.
  • Architecture and priorities pages render expected content.

Main Publish Validation (Blocking for publish)

  • Artifact packaging succeeds for runtime and docs outputs.
  • Manifest payload includes required metadata fields and checksum.
  • Artifact destination write succeeds (bucket/registry placeholder until wired).
  • Publish logs include immutable version identifier.

Scheduled Non-Blocking Checks (Optional)

  • Docs shell deep-link behavior for `tab` and item params.
  • Fallback behavior for missing or invalid catalog entries.
  • Noindex policy checks in page metadata and hosting headers.
