App Template Foundation Requirements

This document defines baseline template requirements for app-scoped docs shell behavior, docs generation/sync parity, and app artifact manifest handoff to platform.

1. Objectives

  • Provide a reusable app repository baseline with minimal setup friction.
  • Keep docs shell behavior and source-to-served parity deterministic.
  • Publish a stable artifact manifest that platform can consume without app source access.

2. Functional Requirements

IDRequirementPriority
FR-TEMPLATE-01 Docs shell must expose tabs for test status, priorities, requirements, testing, and architecture. Must
FR-TEMPLATE-02 Generation script must render markdown-backed pages for priorities and architecture in one run. Must
FR-TEMPLATE-03 Sync script must mirror the entire docs/ tree to hosting/public/docs/. Must
FR-TEMPLATE-04 Template must include a manifest example with app id, version, commit sha, artifact URIs, and checksum. Must
FR-TEMPLATE-05 Workflow scaffold must distinguish app CI/artifact publish from platform deploy responsibilities. Should

3. Acceptance Checks

  • Open /docs/?tab=requirements and verify requirements card/detail/back behavior.
  • Run docs generation and sync, then verify served files under hosting/public/docs/.
  • Confirm noindex directives are present in page metadata and hosting headers.
